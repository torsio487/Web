Welcome to the Deadlock Wiki

Deadlock is an upcoming 6v6 hero shooter game developed by Valve. It combines fast-paced shooter mechanics with deep strategic MOBA elements, featuring dynamic heroes and lane-based combat.

Core Game Features

  • Strategic 6v6 tactical team engagements
  • Skyrail network for quick map traversal
  • In-match item economy and ability upgrades
  • Diverse hero roster with distinct playstyles
